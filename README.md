# Authentication System

A full-stack authentication system built with **Spring Boot** and **Next.js**.

## Tech Stack

### Backend

* Java 21
* Spring Boot
* Spring Security
* JWT
* JPA / Hibernate
* H2 Database

### Frontend

* Next.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* Axios

## Features

* User registration
* User login
* JWT access & refresh tokens
* HttpOnly authentication cookies
* Protected dashboard
* Current user (`/me`) endpoint
* Logout
* Password encryption with BCrypt
* Responsive UI

## Project Structure

```text
authentication-system/
├── authentication-system/        # Spring Boot backend
└── client/                       # Next.js frontend
```
